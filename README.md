# mulga-nalssi-data

토스 미니앱 "물가날씨"가 읽는 주간 농산물 소매가격 데이터 저장소입니다.

- `index.html` — GitHub Pages 서비스 소개 페이지 (https://parksangwook-bit.github.io/mulga-nalssi-data/)
- 가격 JSON과 주 1회 수집 워크플로는 KAMIS Open API 인증키 발급 후 추가합니다.

가격 정보 출처: KAMIS 농산물유통정보(한국농수산식품유통공사). 인증키는 GitHub Secrets에만 보관하고 저장소 파일에는 넣지 않습니다.
